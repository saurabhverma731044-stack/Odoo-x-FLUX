# Brightloop – Subscription Management 
Open `index.html` in a browser (no build step). Demo: any email + any password, pick a role. Sign-up enforces the password rules.

- `js/data.js` – mock data, billing/discount logic (swap for Supabase queries)
- `js/app.js` – auth, role-based nav, dashboard, subscriptions, plans, customers, invoices, payments, discounts, staff
- `css/style.css` – dark teal theme
